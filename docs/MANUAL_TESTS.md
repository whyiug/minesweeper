# 交互、动效与真机验收步骤

这些是可重复执行的验收步骤，**步骤本身不是通过记录**。已实际执行的自动化、截图、录屏及环境限制以 [`../TEST_REPORT.md`](../TEST_REPORT.md) 为准。每次人工执行记录日期、提交、设备、系统、浏览器版本、输入方式和实际结果。截图只能证明某一时刻的视觉状态；动效、声音和连续交互需要观察运行过程。

当前实现环境是远程服务器，真实 Mac 触控板、真实 Safari、iPad / 手机触屏、扬声器听感和生产网络体验仍需对应设备验证。自动化 WebKit 不等于 Safari 真机验收，模拟触屏不等于真实手指与系统手势。

## 准备一个可重复的本地棋盘

普通开发和生产构建使用新随机局。为复查下面的坐标步骤，仅在本地启动显式的 E2E 模式：

```bash
npm ci
npm run dev -- --mode e2e --port 4173 --strictPort
```

打开 `http://127.0.0.1:4173/?seed=42`。端口如已被自己运行的测试服务器占用，可直接使用对应服务；不要停止他人进程。手工启动的服务验证完后在其终端按 Ctrl＋C 关闭。

E2E 模式提供固定随机种子。它是开发测试入口，常规 `npm run build` 的生产产物不读取 URL 种子。下面的“行、列”从 **1** 开始，从上到下、从左到右；每个独立用例开始前刷新页面，保持初级 9 × 9、单击连开、声音关闭的默认设置。不要把固定棋盘练习成绩当作真实随机局成绩；本地测试来源的榜单与生产域名独立。

以下固定序列已用当前真实规则模块计算核对：首点 **第 5 行第 5 列**，展开 37 个安全格；第 1 行第 6 列显示 **1**，第 1 行第 7 列为隐藏安全格，第 2 行第 7 列为雷。它们用于复现，不是对随机生产棋盘的提示。

| ID | 操作 | 应观察到的结果 |

| M01 按下与取消 | 鼠标按住第 5 行第 5 列，先不松开；将鼠标移出棋盘后松开 | 按住时立即出现轻压反馈和表情变化，未提前翻开；移出取消后棋盘仍未开始，计时为零 |
| M02 松开提交 | 重新按下并松开第 5 行第 5 列 | 出现连续空白展开，数字清楚可读；展开过程中规则和计时已经开始，操作不等动画 |
| M03 插旗 / 取消 | 新局，对第 1 行第 1 列右键两次；再 Shift＋点击两次 | 每次只切换一次旗子，金色旗格和旗帜清楚；不生成棋盘、不启动计时；普通点击旗格不会翻开 |
| M04 大面积与快速操作 | 新局，点击第 5 行第 5 列，立即点击第 9 行第 3 列，再立即点击第 1 行第 9 列 | 都是该固定局的安全操作；展开不阻塞下一次操作，目标装饰立即结束，数字与结果符合已提交状态，无复盖或重复开格 |
| M05 快速重开 | 展开刚出现时立即点“新的一局”，连续重复 5 次；再等 1 秒 | 每次都是完整新局，计时重置；旧动画、粒子或声音不修改新棋盘，无旧数字迟到出现 |

为观察瞬态，可录屏后逐帧查看；不要仅截图最终已开棋盘就给 M01、M02、M04、M05 记通过。

## 胜利、声音和减少动效

要重复观察胜利状态，新局保持单击连开，先翻第 5 行第 5 列，然后按以下顺序逐格点击。坐标为“行, 列”：

```text
(9,3) (1,9) (1,7) (4,8) (5,8) (6,1)
(6,9) (7,1) (7,2) (7,4) (7,6) (7,7)
(7,8) (7,9) (8,1) (8,9) (9,8) (9,9)
```

该序列翻开全部 71 个非雷格，不要求插旗。测试模式可复用同样序列观察界面，但生产游戏没有“同题重玩并入榜”的入口。

| ID | 操作 | 应观察到的结果 |
| --- | --- | --- |
| M14 获胜 | 按上面序列完成，观察最后一步；马上尝试点棋盘并重开 | 胜利立即成立，用时冻结；短庆祝与获胜表情、结果文字出现，棋盘不移位；终局操作不修改棋盘，重开立即响应 |
| M15 默认静音 | 新打开页面，在未打开声音开关的情况下翻开、插旗、连开、失败 | 不发声；浏览器不因加载页面而播放音效 |
| M16 五种音色 | 主动点击“开启声音”；分别执行 M02、M03、M06、M14 和 M07 | 翻开、插旗、连开、获胜、失败可区分，音量轻且稳定；大面积展开只有一次批量反馈，不每格叠音，无背景音乐 |
| M17 关闭与停止 | 有声音时关闭开关；获胜短音未完时立即重开；声音开启时切到另一标签页再返回 | 关闭和重开停止旧音；后台切回没有堆积音效突然补播；若浏览器阻止音频，游戏仍可操作，不假报已听到声音 |
| M18 应用减少动效 | 设置中关闭“展开动效”，应用后重复 M02、M03、M06、M14、M07 | 没有展开、旗帜或庆祝的运动效果；数字、旗帜、触雷格、错旗和结果仍清楚；游戏规则和输入不受影响 |
| M19 系统减少动效 | 应用中重新打开动效，同时在设备系统设置中启用减少动态效果；重新观察 M18 的动作 | 系统偏好优先，界面同样减少运动；修改系统偏好后恢复其原先值，并记录实际是否生效 |
| M20 连续操作听感 | 开启声音并快速交替插旗和取消，接着开格，再快速重开 | 声音无无限堆叠或持续残留；响度和舒适度用真实扬声器 / 耳机观察，模拟 AudioContext 的断言不代替听感 |

真实音频验收当前为 **未验证**。在共享服务器的无声浏览器内运行音频 API，只能验证调用和清理行为，不能评价响度、设备输出或 Safari 用户激活策略。
